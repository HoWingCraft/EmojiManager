# EmojiManager
Simply emoji manager based on pyqt

目前功能包括但不限于:
无限制导入导出图集
收藏&解除收藏(收藏图片将无法被删除)
创建父集文件夹
单独删除父集&清空所有父集有关文件
自定义UI颜色(设置中条件)
批量转移子集至其他父集
支持动图浏览
支持修改图片ID
支持修改父集ID
允许调整父集优先级
允许在父集里嵌套父集 (需要设置开启测试)
允许直接导出整个父集（以zip压缩包的形式）
允许导入父集（需要以导出压缩包的形式）
允许批量导入图片（选择文件夹/直接批量选择）
支持添加/移除单个tag，移除后自动清理相关类型
可在设置中永久删除tag
搜索可展开并显示最近5条搜索记录&全部tag
新增基于格式筛选
新增相似度查找(测试功能，不怎么好用，毕竟是数据层面的分析())
父集嵌套可以像俄罗斯套娃无限嵌套，子父集可折叠/展开
折叠状态现在可保存并在启动时恢复（实验性）
新增加密/解密导出导入（实验性，设置中开关，可以肆无忌惮发色图了说是.jpg）
基于哈希值来防图片重复导入(大部分情况下生效)
导入哈希查重可在设置中开关并调整相似比例
在线预览支持:滚轮缩放!拖拽平移!双击复位!!!(给我写力竭了)

正式版更新内容:
移除了 Herobrine
